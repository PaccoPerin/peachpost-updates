# 桃笺 · 情侣桌宠

桃笺是给两个人一起用的 Windows 桌宠。你在手写板上画一颗心，勾选「边写边同步」，对方就能在桌宠旁看着你一笔一笔画完。平时，两个人可以给同一碗里添食、每天打卡，看着小屋里的陪伴天数慢慢增加。

## 下载与启动

桃笺 2.4.1 适用于 **Windows 10 / 11 的 64 位电脑**，解压即可使用。这一版内置了 GitHub 更新地址，今后可以直接在桌宠里检查新版。

1. 两个人各自在 [GitHub Releases](https://github.com/PaccoPerin/peachpost-updates/releases) 找到 `v2.4.1`，在 **Assets** 下下载 `PeachPost-2.4.1-windows-x64.zip`。
2. 将压缩包**全部解压**，打开「桃笺2.4.1」文件夹，双击「桃笺.exe」。第一次启动时，桌宠会出现在桌面右下角。
3. 双击桌宠，或右键选择「打开软件界面」进入小屋。关掉小屋窗口后，桌宠还会陪你、替你收信。想完全退出时，右键选择「退出桌宠」。

## 怎么和对方配对

**两台电脑在同一局域网**  
双方打开「配对设置」，展开「局域网与手动连接」。一方点击「开启局域网共享」→「复制邀请」，把服务地址和 8 位邀请码发给对方。另一方填入这两项，点击「加入小屋」。使用期间，房主需要保持桃笺运行并开启共享。

**两个人在不同地方**  
2.4.1 的安装包里，异地同步服务地址留空。请先向小屋维护者获取已部署的桃笺同步服务 HTTPS 地址。双方在「配对设置」→「设置异地服务」保存同一个地址，以后就可以直接用邀请码配对。一方点「创建异地小屋」并把 8 位邀请码私发给对方，另一方输入后点「加入异地小屋」。异地小屋单独记录信件和养成进度，原来的记录可以在「返回本机小屋」后查看。

## 小屋里可以做什么

- **写信和留提醒。** 右键选「写信」，可以在同一封信里打字、手写或画画。勾选「边写边同步」可以让对方实时看到草稿，点「封好并寄出」就会收入双人信箱。也可以写一封定时信，等约定的时刻再寄出。给自己的提醒在「定时与提醒」里设置，只在自己的电脑上弹出。
- **挑选桌面伙伴。** 「形象衣橱」有 8 款动物和 4 款人物，可以只显示一只，也可以两只并排。还能用自己的照片在本机生成像素贴纸或围巾小偶。大小可从 50% 调到 200%，同一台电脑上的两只一起缩放。
- **一起喂养。** 一个人添一份，两只就能一起吃。两个人也可以各添一份，每人同时最多一份。草莓管 15 分钟（好感 +2），爱心饼干管 2 小时（+8），暖心便当管 8 小时（+20）。桌面平时不显示倒计时，持续饿了才会提醒。喂食、摸头和打卡都能积累经验升级。
- **逗它们玩。** 单击摸头，慢拖会走，快拖会跑。两只在一起时，按住一只持续来回甩动，甩得越有力，它们就分得越远。落到任务栏上方后，它们会慢慢走向彼此，鼠标悬停时还会心虚地停住。也可以拖一只到另一只身边，松手让它们会合。连续 15 分钟没有互动，它们会睡着。

## 已经装过桃笺？

- **2.4.1 用户**右键桌宠选「检查更新」。发现新版后，按提示下载压缩包。
- **2.4.0 用户**在「检查更新」→「设置更新地址」中填入下面的地址并保存，即可在软件里检查新版。
- **2.3.1 及更早版本**可先按上面的「下载与启动」手动升级一次。

2.4.0 可复制的更新地址为 `https://github.com/PaccoPerin/peachpost-updates/releases/latest/download/update.json`。

升级时，先右键退出旧桌宠，把新版完整解压到一个新文件夹，再从新文件夹启动「桃笺.exe」。使用同一个 Windows 账户时，桃笺会沿用原来的设置和本机小屋存档。详细的存档备份方法见压缩包内的《使用说明.txt》。
