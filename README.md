# 桃笺 · 情侣桌宠

桃笺是给两个人一起用的 Windows 桌宠。你在手写板上画一颗心，勾选「边写边同步」，对方就能在桌宠旁看着你一笔一笔画完。两个人共用一个食盆。谁打开小屋、摸摸头或喂食，这一天就会记进陪伴日历。

**2.5.0 更新亮点**　桌宠可以低头让对方摸摸头，也可以靠在一起抱一抱。食柜增加到九种食物，两只会一起吃。你们还可以给各自的角色起昵称，用这个名字给对方寄信。

## 下载与启动

桃笺适用于 **Windows 10 / 11 的 64 位电脑**，解压即可使用。从 2.4.2 起，桃笺内置了小屋同步服务，两个人即使连着不同的 Wi-Fi，也可以直接用邀请码配对。

1. 两个人各自打开[桃笺最新版下载页](https://github.com/PaccoPerin/peachpost-updates/releases/latest)，在 **Assets** 里下载以 `PeachPost-` 开头、以 `-windows-x64.zip` 结尾的软件包。首次使用只需要这个 ZIP。
2. 将压缩包**全部解压**，在解压后的桃笺文件夹里双击「桃笺.exe」。第一次启动时，桌宠会出现在桌面右下角。
3. 双击桌宠，或右键选择「打开软件界面」进入小屋。关掉小屋窗口后，桌宠还会陪你、替你收信。想完全退出时，右键选择「退出桌宠」。

## 怎么和对方配对

双方打开「配对设置」。一方点「创建小屋」，把 8 位邀请码私发给对方。另一方输入后点「加入小屋」。两个人可以使用不同的 Wi-Fi，都只需运行桃笺。在线小屋单独记录信件和养成进度，点击「返回本机小屋」可以查看原来的记录。

在同一局域网，也可展开「局域网与手动连接」。房主点「开启局域网共享」并把服务地址和邀请码发给另一位，另一位填入后点「加入小屋」。使用期间，房主需保持桃笺运行并开启共享。

使用 2.4.1 时，可在「配对设置」的服务选项中手动保存 `https://peachpost-production.up.railway.app`。要在两台电脑上看到昵称和新版互动，请双方都升级。使用自建小屋的房主也请同步更新小屋服务。

## 小屋里可以做什么

- **写信和定时寄出。** 右键桌宠选「写信」，用昵称给对方寄一封带文字和手绘的信。勾选「边写边同步」后，对方能看见你落下的每一笔。在「双人信箱」可以新建定时信，在「待寄」查看与取消预约。
- **给自己留个提醒。** 打开「提醒事项」，选好日期与时分，到点后文字会出现在自己的桌宠旁边。关闭软件期间到期的事项，会在下次打开桃笺时提醒。
- **挑选形象和昵称。** 衣橱里有 8 款动物和 4 款人物。两人分别设置自己的外观和昵称，也可以在本机把照片生成像素形象后分享给对方。单宠显示自己，双宠并排显示。大小可从 50% 调到 200%，同一台电脑的两只一起缩放。
- **一起喂养。** 九种食物各有配图和饱腹时间，从 15 分钟的草莓到 12 小时的双人野餐篮。一个人添一份，两只就会一起吃，两个人也可以各添一份。食物和倒计时在「喂食与养成」查看。桌宠会播放进食动画，持续饿了会就近弹出提醒。
- **记录陪伴。** 任一方当天互动，小屋就会自动记录一天，同一天只算一次。喂食、摸头和其他快捷互动还能积累成长经验。
- **逗它们玩。** 右键可以让人物抬手、动物举爪比心，也可以摸头、抱抱或亲亲。双宠会靠近对方做动作，单宠可以抱住自己、朝你送飞吻。慢拖会走，快拖会跑。两只在一起时，按住一只持续来回甩动，甩得越有力，它们就分得越远。落到任务栏上方后，它们会慢慢走向彼此，鼠标悬停时还会心虚地停住。也可以拖一只到另一只身边，松手让它们会合。连续 15 分钟没有互动，它们会睡着。

## 已经装过桃笺？

- **2.4.1 及更新版本**打开软件窗口，在左侧选「检查更新」。发现新版后，按提示下载压缩包。
- **2.4.0 用户**在「检查更新」→「设置更新地址」中填入下面的地址并保存，即可在软件里检查新版。
- **2.3.1 及更早版本**可先按上面的「下载与启动」手动升级一次。

2.4.0 可复制的更新地址为 `https://github.com/PaccoPerin/peachpost-updates/releases/latest/download/update.json`。

升级时，先右键退出旧桌宠，把新版完整解压到一个新文件夹，再从新文件夹启动「桃笺.exe」。使用同一个 Windows 账户时，桃笺会沿用原来的设置和本机小屋存档。详细的存档备份方法见压缩包内的《使用说明.txt》。
